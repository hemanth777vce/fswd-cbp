give commands for running

Here are the commands to run DevPulse on your machine:

Option 1: Dual-Terminal Method (Recommended for Development)

Open two separate terminal windows inside the project root (fswd-CBP):

Terminal 1: Start the Backend Server
bash
cd server
npm run dev

Backend runs on: http://localhost:5000
(Uses nodemon for auto-restart on changes)

Terminal 2: Start the Frontend Client
bash
cd client
npm run dev

Frontend runs on: http://localhost:5173

Option 2: Run Using Root Scripts (From fswd-CBP root folder)

If you have already installed dependencies, you can start each service directly from the root directory:

Terminal 1 (Backend):

bash
npm run server

Terminal 2 (Frontend):

bash
npm run client
If Running for the Very First Time (Install Dependencies)

Run this single command from the project root to install all dependencies for both server and client:

bash
npm run install:all
How to Run the Automated Test Suites

To verify authentication, CRUD, likes, and backend security guardrails:

bash
# 1. Run Authentication & JWT Tests (14 assertions)
node server/test-auth.js
# 2. Run Full API, Posts, Likes & HTTP 403 Security Tests (16 assertions)
node server/test-all-api.js
🌐 Open in Your Browser

Once both servers are running, open: 👉 http://localhost:5173
